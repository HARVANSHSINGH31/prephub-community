# Code of Conduct

- Be someone a fresher would actually want advice from. No gatekeeping, no "just LeetCode harder."
- Never post proprietary or NDA-covered interview content verbatim. Describe the type of question, not a leaked question bank.
- No paid placements, referral scams, or "DM me for guaranteed job" posts. This project is free and stays free for students.
- Corrections and disagreements go through issues and pull requests, not arguments in the comments.
- Verified badges are earned once and can be revoked by the maintainers or placement cell if misused.
