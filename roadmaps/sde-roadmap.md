# Roadmap: SDE / SDE Intern Roles

A suggested order to prepare in, built from patterns across the company guides in `companies/`. Not a substitute for reading the actual guide for your target company — start here, then go read that.

## Phase 1 — Foundations (4–6 weeks)
- Arrays, strings, hashmaps
- Recursion and basic sorting/searching
- Time/space complexity — be able to explain yours out loud, not just compute it

## Phase 2 — Core DSA (6–8 weeks)
- Trees and graphs (BFS/DFS, at minimum)
- Dynamic programming — start with 1D, then grid-based
- Two-pointers / sliding window patterns

## Phase 3 — CS Fundamentals (parallel, 3–4 weeks)
- Operating systems: processes/threads, memory management, deadlocks
- DBMS: normalization, indexing, joins, basic SQL fluency
- Computer networks: OSI basics, HTTP/TCP fundamentals (only if a target company's guide flags this)

## Phase 4 — Applied / Company-Specific (2–3 weeks before applying)
- Read every guide under `companies/` for your target list
- Note the *specific* round formats and skill bars each one calls out — they are not the same
- Do at least 2–3 mock interviews with a verified alum or senior before your real interviews

## Phase 5 — Resume & Behavioral (ongoing)
- Use `resources/resume-checklist.md`
- Know every project on your resume well enough to defend it under follow-up questions
